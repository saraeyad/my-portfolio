A modern, interactive portfolio built with React, TypeScript, Vite, and Three.js.

## Features

- Animated hero and section transitions
- 3D project experience
- Project details drawer with image carousel
- Contact page wired to email
- Centralized content in data/config files for easy updates

## Customize Content

- `src/data/portfolio.ts`  
  Main portfolio content:
  - personal info
  - skills
  - projects
  - experience

- `src/config.ts`  
  Global profile/contact config:
  - name
  - role
  - email
  - WhatsApp
  - social links

## Project Structure

```text
src/
  components/
  pages/
  data/portfolio.ts
  config.ts
  index.css
```
